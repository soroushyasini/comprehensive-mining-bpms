# Persian web fonts

Unmodified Vazirmatn Regular, Medium, SemiBold and Bold font files are bundled
for same-origin rendering. The isolated CSS family `EmcoreVazirmatn` prevents
changing a host application's font face. Original project:
[Vazirmatn](https://github.com/rastikerdar/vazirmatn).
